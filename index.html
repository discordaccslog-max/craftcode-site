What the lessons cover

The fundamentals, one concept at a time

Ten lessons, split into three parts. They start from “what is a program?” and build up the core ideas most programming languages share. All examples and exercises use Python 3.

  1. 01Part 1

    How programs run

    What code is, how a computer follows instructions in order, and your first program.

  2. 02Part 1

    Setting up your tools

    Installing Python and a code editor, organizing your files, and running code from your computer.

  3. 03Part 1

    Values and variables

    Numbers, text and true/false values: storing them, naming them, and changing them.

  4. 04Part 2

    Making decisions

    Comparisons and conditions: getting a program to do different things depending on its data.

  5. 05Part 2

    Repeating work with loops

    Running the same steps many times, counting, and stepping through a set of items.

  6. 06Part 2

    Functions

    Breaking code into small, named, reusable pieces that take inputs and give back results.

  7. 07Part 3

    Lists and collections

    Keeping groups of values together, looking things up, and adding or removing items.

  8. 08Part 3

    Working with text and input

    Reading what a user types, combining and formatting text, and printing results.

  9. 09Part 3

    Reading errors and debugging

    What error messages are telling you, and a step-by-step way to track down mistakes.

  10. 10Part 3

    Putting it together

    Planning and reading a complete program that combines every earlier topic.

This describes what the lessons explain and give you practice with. How much you take from them depends on you.

What you need to use the files

No paid software is needed.

  • A desktop or laptop computer (Windows, macOS or Linux)
  • A way to open .zip files (built into most operating systems)
  • A PDF reader for the lesson guide (most web browsers can open PDFs)
  • A plain-text or code editor (any free editor works)
  • Python 3, free from python.org. Installation is covered in Part 1, Lesson 2.
  • An internet connection to download the files and tools

A phone or tablet can display the lessons, but the exercises are designed to be done on a computer.

Questions before you buy

Which part should I start with?

If you're new to programming, start with Part 1. Parts 2 and 3 build on the earlier parts and assume you know what they cover. The Complete Edition contains all three parts in one download.

Is the Complete Edition different from buying all three parts?

It has the same ten lessons, exercises, solutions and examples as Parts 1, 2 and 3, combined into a single PDF guide and one download. Nothing extra is added.

How do I receive the files?

After your payment is confirmed, you get a link to download a .zip file. If you can't find it, check your spam or promotions folder first, then contact us with your order number. See the delivery policy.

What file formats are included?

Each download is a .zip file containing a PDF lesson guide, Python (.py) exercise files with solutions, Python (.py) example programs, and a README.txt. Page counts, file counts and download sizes are listed on each product page.

What software do I need?

A computer, a PDF reader, a free code editor, and Python 3 (free from python.org). Part 1, Lesson 2 walks through installing them. See What you need to use the files for the full list.

Not for Part 1 or the Complete Edition. The lessons assume you've never programmed. You do need to be comfortable with everyday computer tasks like installing software, unzipping files and working with folders.
